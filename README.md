# Watch Hunt V1

PWA locale pour trier des annonces de montres vintage.

## Fonctions
- Swipe gauche : rejeter
- Swipe droite : aimer
- Swipe haut : ajouter à "À acheter"
- Favoris ♥ séparés
- Historique
- Modèles bannis
- Prompt automatique 60 % exploitation / 40 % exploration
- Import `WATCH_FEED_V1`
- Stockage local IndexedDB
- Sauvegarde/restauration JSON
- Installation sur iPhone via Safari > Partager > Ajouter à l’écran d’accueil
